If you want to test the project, 
1. first clone the project by running "git clone https://github.com/success619/email-verification-backend-.git"
2. install the dependencies by running "npm install"
3. pass your environmental variables (GMAIL_USER, GMAIL_PASS) arguments while running the project with "npm start" or create ".env" file and write down the environmental variables

4. GMAIL_USER refers to the auth email address of the user specifically someone or organinzation who owns the server. eg. example@gmail.com
5. GMAIL_PASS refers to the auth password of the user specifically someone or organinzation who owns the server. to get this password, first you have to log into your gmail account and make sure to enable the 2-step verification, then search for 'app password', give a name of app and the password will be generated for you;

6. to start the project is "npm start"
